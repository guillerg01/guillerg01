### 🚀 What I do

- **Fullstack architecture** — domain modules, clean/hexagonal boundaries, typed APIs, Repository and Singleton patterns; reusable components and services.
- **Frontend & performance** — React/Next.js and Vue/Nuxt dashboards, TanStack Query, optimistic updates with rollback, request cancellation, LRU and IndexedDB caching.
- **Backend reliability** — NestJS, PostgreSQL, transactions, state machines, persistent queues, cron, bounded batches, checkpoints, retries and offline synchronization.
- **Mobile** — React Native/Expo, Android native integration, inspection workflows, notifications and foreground/headless processing.
- **Payments & Web3** — Stripe subscriptions, TS Pay HMAC callbacks, Oxapay, Fincode/3D Secure, Privy, ethers.js and wallet/NFT interfaces.
- **AI, scraping & automation** — LangGraph agents, Ollama, Whisper, structured outputs, resumable property scraping, Telegram bots and MTProto auditing scripts.
- **Healthcare & digital signing** — OHIF/Cornerstone, DICOM SR, dynamic reports, PKCS#12, CMS/PKCS#7, Web Crypto and document verification.
- **Product engineering** — CRM/admin systems, embeddable HTML/JavaScript chat, maps, media management, accessibility, automated tests and distributed-team collaboration.
